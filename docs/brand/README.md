# ANCHOR team branding

Banner and badge for the team card on the CDAO hackathon platform.

| File | Use |
| --- | --- |
| `anchor-banner-centered.png` | Banner, 1600x400 (recommended) |
| `anchor-banner-split.png` | Banner, wordmark left, message status tags right |
| `anchor-banner-bright.png` | Banner, matches the platform's default cyan block |
| `anchor-badge-simple.png` | Team avatar, 1024x1024 (recommended, reads at small sizes) |
| `anchor-badge-seal.png` | Team avatar with ring text, for larger displays |
| `anchor-banner-preview.png` | All variants mocked inside the team card |

Banners keep their content above the bottom-centre strip, where the round avatar overlaps.

Regenerate with `node docs/brand/render.js` from `docs/brand/` (needs Playwright and the Inter font).
